# 出入库单四态改造与退库 · 交互原型

仓库管理系统仓储模块的交互式 HTML 原型，用于可视化《出入库单-四态改造与退库-技术方案》中的核心设计。

## 功能范围

- **入库单列表**：统一四态（草稿/已生效/已完成/已作废）状态标签，行操作按钮按状态机显隐
- **出库单列表**：四态状态展示
- **入库/出库单编辑页**：表单 + 明细表格 + 生效/反生效/执行/作废 按钮联动
- **退库单（新增）**：退库单列表 + 新增退库（选择原单 → 自动带出明细 → 填写退库数量/退库原因）
- **四态状态机说明**：状态流转图 + 操作×状态矩阵

## 统一状态机

```
草稿(0) ──生效──► 已生效(1) ──执行──► 已完成(2)
   ▲                  │                  │
   └──── 反生效(弃审) ─┘   作废           ▼
                    ▼             退库单 草稿→生效→完成
               已作废(9)
```

| 操作 \ 状态 | 草稿(0) | 已生效(1) | 已完成(2) | 已作废(9) |
|---|---|---|---|---|
| 保存/编辑/删除 | ✅ | ❌ | ❌ | ❌ |
| 生效 | ✅ | ❌ | ❌ | ❌ |
| 反生效 | ❌ | ✅ | ❌ | ❌ |
| 执行(入库/出库/退库) | ❌ | ✅ | ❌ | ❌ |
| 作废 | ✅ | ✅ | ❌ | ❌ |
| 生成退库单 | ❌ | ❌ | ✅ | ❌ |
| 详情/打印 | ✅ | ✅ | ✅ | ✅ |

## 如何打开

直接双击 `出入库四态改造与退库-交互原型.html` 在浏览器打开即可（Tailwind CSS 通过 CDN 引入，需联网）。
或启动本地静态服务器：

```bash
python -m http.server 8123
# 访问 http://127.0.0.1:8123/出入库四态改造与退库-交互原型.html
```

## 技术说明

- 单文件 HTML（内联 CSS/JS），无构建依赖，离线可改
- 交互用原生 JavaScript 模拟：点击操作按钮实时演示状态流转、按钮显隐联动、明细带出
- 所有数据为本地 mock，不含真实业务数据
- 按钮权限标识参考技术方案 §6.1（如 `warehouse:inboundOrder:audit` / `unAudit` / `store` / `void` / `print`）

> 原型仅用于演示交互与视觉，非实际业务系统。
