# 出入库单四态改造与退库 · 交互原型

仓库管理系统仓储模块的交互式 HTML 原型，用于可视化《出入库单-四态改造与退库-技术方案》中的核心设计。

## 功能范围

- **入库单列表**：统一四态（草稿/已生效/已完成/已作废）状态标签，行操作按钮按状态机显隐
- **出库单列表**：四态状态展示
- **入库/出库单编辑页**：表单 + 明细表格 + 生效/反生效/执行/作废 按钮联动
- **退库单（新增）**：退库单列表 + 新增退库（选择原单 → 自动带出明细 → 填写退库数量/退库原因）
- **四态状态机说明**：状态流转图 + 操作×状态矩阵

## 统一状态机

```
草稿(0) ──生效──► 已生效(1) ──执行──► 已完成(2)
   ▲                  │                  │
   └──── 反生效(弃审) ─┘   作废           ▼
                    ▼             退库单 草稿→生效→完成
               已作废(9)
```

| 操作 \ 状态 | 草稿(0) | 已生效(1) | 已完成(2) | 已作废(9) |
|---|---|---|---|---|
| 保存/编辑/删除 | ✅ | ❌ | ❌ | ❌ |
| 生效 | ✅ | ❌ | ❌ | ❌ |
| 反生效 | ❌ | ✅ | ❌ | ❌ |
| 执行(入库/出库/退库) | ❌ | ✅ | ❌ | ❌ |
| 作废 | ✅ | ✅ | ❌ | ❌ |
| 生成退库单 | ❌ | ❌ | ✅ | ❌ |
| 详情/打印 | ✅ | ✅ | ✅ | ✅ |

## 如何访问

### 方式一：本地直接访问（最快）

1. **双击** `启动原型.bat`，浏览器会自动打开 `http://127.0.0.1:8123/`
2. 或直接双击 `index.html` 用浏览器打开（无服务器也可，仅 Tailwind CDN 需联网）

### 方式二：局域网访问（同事在同一内网）

在 `原型` 目录打开 PowerShell 执行：

```powershell
python -m http.server 8123 --bind 0.0.0.0
```

然后同事访问 `http://你的内网IP:8123/`（用 `ipconfig` 查看 IP）。

### 方式三：部署到在线平台

| 平台 | 操作 |
|---|---|
| **Netlify** | 打开 https://app.netlify.com/drop ，把整个 `原型` 文件夹拖进去，自动生成 `xxx.netlify.app` 链接 |
| **Vercel** | 导入该 Git 仓库（`vercel.json` 已就绪），自动部署 |
| **GitHub Pages** | 推送后仓库 Settings → Pages → 选 master 分支（`_config.yml` 已就绪），访问 `https://用户名.github.io/仓库名/` |

> 注：Gitee Pages 服务已下线（2024-07），无法通过 Gitee 部署在线页面。

## 技术说明

- 单文件 HTML（内联 CSS/JS），无构建依赖，离线可改
- 交互用原生 JavaScript 模拟：点击操作按钮实时演示状态流转、按钮显隐联动、明细带出
- 所有数据为本地 mock，不含真实业务数据
- 按钮权限标识参考技术方案 §6.1（如 `warehouse:inboundOrder:audit` / `unAudit` / `store` / `void` / `print`）

> 原型仅用于演示交互与视觉，非实际业务系统。
